# Friendsgiving 2026

A standalone invitation and RSVP planner for dinner with friends. Built with React, TypeScript, Tailwind CSS, and Vite. The date and location are tentative.

Guests fill out the planner and review their answers. The site formats a private message addressed to Kai on WhatsApp. Guests tap Send inside WhatsApp to deliver it. A copy button is available for guests who want to send the text through another private channel. An unfinished draft stays in the guest’s browser tab.

## Local development

Use Node 24. Run `npm ci`, then `npm run dev`. Run `npm run build` to type-check and build the static site.

GitHub Actions builds and publishes the site to this repository’s GitHub Pages URL.
